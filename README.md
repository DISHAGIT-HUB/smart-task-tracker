# 📌 Smart Task Tracker

A simple and user-friendly web application to manage daily tasks efficiently using a Kanban-style board. This project helps users organize their tasks into different stages like **To Do**, **In Progress**, and **Done** with date and time scheduling.

---

# 🚀 Features

* Add new tasks easily
* Assign date to tasks
* Organize tasks into:

  * To Do
  * In Progress
  * Done
    
* Move tasks between sections
* Clean and responsive UI
* Beginner-friendly implementation

---

# 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

---

# 📂 Project Structure

```
Smart-Task-Tracker/
│── index.html      # Main UI structure
│── style.css       # Styling of the application
│── script.js       # Functionality and logic
```

# ⚙️ How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in any browser

That’s it! 🎉

---



# 💡 How It Works

* User enters task name and date
* Task is added to **To Do** section
* Tasks can be moved to **In Progress** or **Done**
* Helps in tracking daily activities and productivity
